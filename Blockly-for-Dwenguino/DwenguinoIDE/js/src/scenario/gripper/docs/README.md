# Gripper Scenario Documentation

This folder groups the documentation that belongs to the gripper scenario.

## Structure

- `scenario/`: Gripper-model, descriptor, reference-geometry, and implementation guides
- `constraint-solver/`: Constraint-system, solver-tuning, and per-entity-weight references

## Naming

- Markdown files in this folder use lowercase kebab-case names.
- Example and runtime asset filenames keep their existing project-specific names.

## Related Assets

- `../examples/`: Example descriptors and example-only support files
- `../descriptors/`: Runtime descriptor files used by the scenario
- `../legacy/`: Non-runtime backups kept out of the active source root
